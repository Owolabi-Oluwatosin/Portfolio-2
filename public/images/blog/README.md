# Blog cover images

Drop blog post cover images here. Recommended: 16:9, at least 1200×675px, PNG or JPG.

To add a cover for a post, add the file here and set `cover` in that post's
frontmatter, e.g.:

```
---
title: "..."
date: "..."
category: "..."
excerpt: "..."
cover: "/images/blog/your-post-slug.png"
---
```

Posts without a `cover` set automatically render a branded gradient fallback
with the post title, so cards never look broken while you're still adding
images.
