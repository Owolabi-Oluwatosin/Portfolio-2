# Project cover images

Drop project cover images here. Recommended: 16:9, at least 1200×675px, PNG or JPG.

Expected filenames (referenced by the `image` field in `src/lib/content.ts`):

- `playzeet.png` — used by the PlayZeet project (currently the only project with an `image` set)

To add a cover image for any other project, add the file here and set its
`image` field in `content.ts`, e.g. `/images/projects/vitascan.png`. Projects
without an `image` set fall back to a gradient placeholder automatically.
